スマホがレトロPCのコントローラーに

■ プロモーションテキスト（170文字以内）
------------------------------------------------------------

Mimic X デバイスとペアにすることで、iPhone / iPad がレトロPCのジョイスティック・キーボードに早変わり。X68000・MSX などの実機やエミュレータに、USB-MIDI 経由で本物の操作感を取り戻します。連射・6ボタンパッド・X68000 配列キーボードに対応。


■ 説明文 (Description)
------------------------------------------------------------

Mimic X は、別売の Mimic X ハードウェアと組み合わせることで、
お手持ちの iPhone / iPad をレトロPC用の HID デバイス
（ジョイスティック・キーボード・マウス）として使えるようにする
USB-MIDI コントローラーアプリです。

X68000・MSX をはじめとするレトロPCの実機や、それらの
エミュレータが動く環境に対して、当時のコントローラーと同じ
操作感を取り戻すことを目的としています。


◆ こんな方に
・X68000 や MSX などレトロPCの実機を所有している方
・当時のジョイスティック / キーボードが故障して困っている方
・実機用のコントローラーをこれ以上増やしたくない方
・スマートフォンの画面いっぱいの仮想パッドで遊びたい方


◆ ジョイスティックモード
画面上の仮想ジョイスティックでゲームを操作できます。

・ATARI 2 ボタン互換モード
・メガドライブ 6 ボタン ファイティングパッド互換モード
・リブルラブル専用 2 本レバーモード
・ボタンごとの連射（ターボ）ON / OFF と連射速度の設定
・方向キーの不感エリア（デッドゾーン）調整
・ボタンのヒット範囲拡張（指の腹での同時押し、スライド入力に対応）


◆ キーボードモード
レトロPCのキーボードレイアウトを画面上に再現します。

・X68000 キーボード配列に対応
・実機からのキーボード LED 制御信号の受信に対応


◆ 動作に必要なもの（重要）
本アプリ単体では動作しません。以下が別途必要です。

・Mimic X ハードウェア（USB-MIDI 対応のマイコン基板）
・接続先となるレトロPC本体、またはエミュレータ環境
・iPhone / iPad と Mimic X ハードを接続するための
  USB ケーブル（Lightning / USB-C 対応の Camera Adapter 等）

ハードウェアの基板データ・ファームウェアはオープンソースで
公開されています。詳細は以下をご確認ください。

  https://github.com/kunichiko/MimicX-hardware
  https://github.com/kunichiko/MimicX-firmware


◆ オープンソース
本アプリは Flutter で開発されたオープンソースソフトウェアです。
ソースコード・ライセンスはアプリ内「このアプリについて」から
確認できます。

  https://github.com/kunichiko/MimicX-app
