# プライバシーポリシー (Mimic X)

最終更新日: 2026年5月23日

大中 邦彦（以下「開発者」）は、iOS / Android / macOS / Windows アプリ「Mimic X」（以下「本アプリ」）におけるユーザーのプライバシーを尊重し、以下のとおりプライバシーポリシーを定めます。


## 1. 収集する情報

**本アプリは、ユーザーの個人情報を一切収集しません。**

具体的には、本アプリは以下のいずれの情報も収集・送信・保存しません。

- 氏名、メールアドレス、電話番号などの個人を特定できる情報
- 位置情報
- 連絡先、写真、カレンダー等の端末内のデータ
- 広告 ID（IDFA / AAID）等のトラッキング識別子
- 利用状況・操作ログ・クラッシュレポートなどの分析データ


## 2. 端末内に保存されるデータ

本アプリは、以下の設定値をユーザーの端末内にのみ保存します。これらの情報が開発者や第三者のサーバーに送信されることはありません。

- ジョイスティックの操作設定（連射速度、デッドゾーン等）
- 直近に選択していたチャンネルやモードなどの状態

これらは OS 標準の設定保存領域（iOS の `UserDefaults` 等）に保管され、アプリをアンインストールすると削除されます。


## 3. 外部通信について

本アプリは、インターネットを介した外部サーバーとの通信を一切行いません。

本アプリの通信は、USB-MIDI 経由で接続された **Mimic X ハードウェアとのローカル通信のみ** です。この通信内容（ボタン操作・キー入力など）は、接続先のレトロPC等の制御に使われるのみで、端末外のネットワークに送出されることはありません。


## 4. 第三者サービスについて

本アプリは、解析ツール、広告 SDK、クラッシュレポートツールを含む、いかなる第三者サービスも利用していません。


## 5. 子どものプライバシー

本アプリは特定の年齢層を対象にしたものではありませんが、個人情報を一切収集しないため、13歳未満を含むすべての年齢のユーザーが安全に利用できます。


## 6. ポリシーの変更

本ポリシーの内容を変更する場合は、本ページの記載を更新します。重要な変更がある場合には、アプリの更新内容（リリースノート）にもその旨を記載します。


## 7. お問い合わせ

本ポリシーに関するご質問は、以下のリポジトリの Issue よりお寄せください。
